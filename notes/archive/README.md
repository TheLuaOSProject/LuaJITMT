# Historical notes archive

These files are retained as implementation history and evidence, but they are
not authoritative descriptions of the current branch. Many checkpoint notes
describe deliberate fail-closed boundaries that later tranches opened, and
some roadmaps or known-gap sections are now stale.

- `aarch64-checkpoints/`: 76 Apple ARM64 port investigations and incremental
  checkpoints through 2026-08-28.
- `pre-aarch64/`: 847 earlier LuaJITMT implementation, audit, test, roadmap,
  and compatibility notes.
- `complaints/`: 15 historical environment, toolchain, and test-runner issue
  reports.

Files remain flat inside each bucket so existing relative links between related
notes continue to work. Use [`../README.md`](../README.md) for current status
and [`../architecture-constraints.md`](../architecture-constraints.md) for the
durable review constraints.
