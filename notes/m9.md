# M9 Notes

Performance closing setup:

- Added `collectgarbage("stats")` as a read-only benchmark telemetry surface.
  It returns a table with existing GC2 counters for cycle requests/starts,
  allocation pacing, assist and worker progress, owner sweep progress, weak
  clearing, finalizer queueing, and live estimates. This wires the stats called
  out in `plan/13_testing_and_benchmarks.md` without changing collector pacing or
  phase behavior.
- Added `tests/t-gc-stats.lua` and `tools/ci/m9_gc_stats.sh`, covering the stats
  table under interpreter and default-JIT modes. The multi-thread benchmark now
  prints a stable subset of these fields while retaining a fallback for older
  binaries.
- Still pending from the M9 gate: real multi-core benchmark runs, geomean
  regression accounting, and the mutator-observed poll-latency probe.
