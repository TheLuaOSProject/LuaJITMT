Admission and publication were reviewed in input/fix/src/lj_ccall.c:1754, :2191, and :2220, with native publication in lj_safepoint.c:537. Geometry checks exact current TLS/dispatch carrier, owner, stack bounds, slot alignment, prefix, and root/base/top/jitbase offset ordering using integer arithmetic. TraceVec identity/pin and matching generated vmstate are required. Every ordinary rejection, including capacity, remains before the two new stores. No allocation, stack relocation, owner poll, callback, or ordinary failure intervenes between successful validation and the stores; all later operations before lj_native_enter are local bookkeeping and release publications. Generated and ordinary nesting were reviewed in lj_ccall.c:1939-2058, lj_ccallback.c:826-870, :1040-1140, :1250-1380, and vm_x64.dasc:3431-3542. A generated callback suspends the exact ACTIVE top, clears jit_base, closes native admission, and polls before setting up its Lua continuation. The new geometry is therefore available both to that poll and to callback_conv_args. Nested generated calls may push only over SUSPENDED older frames and publish their own validated current geometry. An interpreted foreign call inside callback Lua has no new generated frame; callback_suspend recognizes the SUSPENDED top and leaves the older generated continuation intact. Callback continuation frames store stack offsets, and their encoded predecessor restores the appropriate caller base on return. The change neither replaces those offsets nor restores an older outer frame while an inner callback is active.

Remote scan authority was reviewed in lj_ccall.c:2073-2185 and lj_gc2.c:8898-9237. Exact remote certification requires native admission plus stable frame sequence, current carrier/state identity, pinned trace identity, and the existing consumed-poll certificate. Only the top ACTIVE frame supplies saved stack geometry. Older SUSPENDED frames and a suspended-only stack contribute exact trace/result roots; their pre-callback base/top are explicitly not current stack authority. The conservative parked owner scan supplies current stack roots in that case. Publishing owner geometry before entry is consistent with both paths and fixes the first suspended owner poll. This review does not assume the frame seqlock or a stack-body lease alone prevents relocation, and does not claim a new remote-scan lifetime protocol.

Return, unwind, and relocation were reviewed in lj_ccall.c:2334-2478, lj_safepoint.c:559-614, lj_state.c:65-101, lj_ccallback.c:922-970, lj_ffrecord.c:1559-1623, and lj_trace.c:6818. Generated leave first closes native access and resolves consumed-poll work before finishing or popping its frame. A callback marks the call for forced interpreter exit; POSTCALL retains the exact pin until protected caller-snapshot restoration and cleanup. The DONE exit cannot side-link past that cleanup. Normal no-callback return leaves the valid materialized caller geometry until subsequent generated publication or interpreter snapshot restoration; restoring the former stale interpreter pointers would recreate the defect. On stack growth, resizestack adjusts L->base/top; generated frames and callback continuations retain byte offsets, and callback resume reconstructs jit_base from the current stack. Error paths use the existing callback unwind and POSTCALL pin cleanup rather than adding a new pointer rollback. These mechanics cover relocation without trusting a pre-growth raw stack address.

The final dedicated fixture uses a real Linux int32 callback ABI, holds its FFI callback/function objects live, and calls the actual generated path. Starting the numeric loop at zero with its first body skipped preserves the stale-top trigger instead of accidentally repairing it with an interpreted FFI call. The result oracle remains 6640, with real ACTIVE/SUSPENDED snapshots, generated-entry counts, callback counts, and native exits. It does not manufacture a native frame or overwrite stack metadata to obtain a pass. Three fresh-state modes require ordinary callback preservation, an actual lua_checkstack relocation followed by full collection, and generated Lua-error unwind with empty frame/mirror state and zero trace pins. Disabling JIT for the callback body is a fixture scheduling choice that isolates this boundary; it is not a runtime requirement of the fix. The final version removes the unrelated struct payload/XSTORE.
