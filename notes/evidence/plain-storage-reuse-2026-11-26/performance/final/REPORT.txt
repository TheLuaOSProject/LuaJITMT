Method
The original growth.lua is byte-identical to the first churn investigation. Each process warms1,000 cycles, performs a full collection, then runs40 rounds of20,000 reset/put/get cycles using a1KiBstring. Every cycle checks returned contents; every round checks the buffer is empty. JIT remains enabled. Three paired samples compare old and final binaries for each policy; order alternates within samples. All timed processes run sequentially onCPU 8. Root builds/tests on other cores can affect shared-machine timing, so raw rows and paired ranges are retained.
Policies: automatic collection; automatic plus explicit fullGC every20,000 cycles; automatic plus fullGC every100,000 cycles. Work CPU excludes diagnostic I/O and explicit collection time. Every stage captures all scalar public GC stats, Lua-accounted bytes and synchronized /procRSS /VM  while the child waits for controller acknowledgment. Observer allocations may affect collection scheduling but are identical across variants. Independent allocator counters establish the physical mechanism directly.
All 18 policy processes and both census embeddings pass their workload assertions:720 timed rounds,1,566 policy snapshots and56census snapshots. All /proc snapshots report one OS thread. This package does not claim multi-mutator coverage.

Physical allocator census
The same private census.c is linked separately against unchanged old and final static libraries. It reads only the current TG's arena lists, flags, block/mark/late planes, bounded allocation extents, remote gate states and free-bin histograms. It does not mutate allocator metadata. Each embedding performs200,000 cycles, then explicit b:free(), drops references, flushes traces and performs five full collections.
At200,000 cycles: old has3,870 owned PLAIN arenas and50,250 late starts occupying208,232,928 bytes; final has5 arenas and19 pending late starts occupying78,736 bytes.
After explicit free: final has one late start for the just-retired final backing. After the first fullGC it has zero late starts and zero late extents; they remain zero after five collections. The old runtime retains50,251 late starts and208,237,072 late bytes after all five collections.
Free capacity is reusable in the final runtime: after the fifth fullGC, bin 31 has83 nodes including19 large enough for a 259-cell backing; old bin 31 has3,956 nodes and zero fitting nodes. Final owned PLAIN arenas remain at5. Remote CLOSED/SEALED/PENDING/active-actor counters are zero at the selected checkpoints. Complete histograms and every stage are retained.
