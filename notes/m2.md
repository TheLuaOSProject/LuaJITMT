# M2 Notes

x64 TG dispatch-base switch:

- Moved the x64 VM `DISPATCH` register setup from `GG.dispatch` to
  embedded `GG.main_tg.dispatch` with `GG_G2TGDISP`.
- Rebased x64 VM global/JIT offsets through `TG_DISP2G`/`TG_DISP2J` and
  per-thread fields through `DISPATCH_TG(...)`.
- Rebased x64 JIT GC64 dispatch-relative code generation through
  `J2TG(as->J)->dispatch`.
- Fixed a verification failure in `lj_ir_ggfload` lowering: `FLOAD nil`
  pseudo-fields still subtracted `GG_OFS(dispatch)`, so base-metatable loads
  were emitted with old-dispatch offsets and the stock runner crashed in
  `test.lua:186`. `asm_fusefref` now subtracts `GG_OFS_TGDISP`.
- Updated `lj_asm_patchexit` GC-check recognition to match the new TG-relative
  vmstate displacement.
- This remains an embedded-main-TG bridge. Slow global/JIT paths still use
  fixed offsets from `GG.main_tg.dispatch`; later attachable TG work should
  replace those with `TG.gl` / `g->jitp` loads where TG blocks are no longer
  adjacent to `GG_State`.
