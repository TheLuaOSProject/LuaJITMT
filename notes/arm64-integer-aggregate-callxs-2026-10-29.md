# Darwin ARM64 integer aggregate CALLXS arguments (2026-10-29)

This checkpoint admits one narrowly bounded Darwin AAPCS64 argument shape in ARM64 FFI traces: a by-value C struct up to eight bytes, represented in one available GPR, whose direct members are nonoverlapping integer, boolean, or enum scalars. Supported total widths are 1, 2, 4, and 8 bytes. The call must be fixed-arity and have a free argument GPR. The recorder loads the exact CData payload width, while the original CData TValue remains rooted in its Lua frame slot through native XSAVE/enter/leave.

The classifier rejects unions, nested composites, HFA/float members, bitfields, vectors, references, over-aligned or oversized aggregates, stack-passed aggregate arguments, and variadic aggregate arguments. It does not add aggregate return support. These limits are deliberate; total size alone is not treated as sufficient ABI evidence.

The semantic and post-register-allocation admission walks independently bind the CData source and CType identity, exact payload XLOAD width and offset, fixed source argument position, CARG/CALLXS association, GPR allocation, and saved snapshot roots. The fixture mutates the payload offset and call argument binding in each pass and requires rejection, in addition to existing wrong-type/source and physical-register negatives. A live peer remains attached during native evidence; per-width native finish counters require selected roots with the matching XLOAD width. After a full GC, the pair case requires the U64 root to remain published and re-enter native code before taking an exit.

Validation: `tools/ci/arm64_jit_integer_aggregate_args_contract.sh` passed `arm64-assert`, `arm64e-assert`, `arm64-release`, and `arm64e-release` on the current branch. The contract runs the independent scalar CALLXS admission fixture before the new aggregate fixture in each profile. The private CALLXS fixture copies only the readable `[nk,nins)` biased IR range. An earlier test-fixture version copied from the biased `T->ir` base and crashed in `memmove`; the final helper avoids reading below `nk`. For clone-based CALLXS negatives, the narrow test-only initializer remaps root-owned SNAP_FRAME KNUM continuation PCs alongside snapshot footers, while preserving only the independently derived FFI `__call` meta_pc. Its semantic fixture J is embedded in a private `GG_State` so `J2G(J)` remains valid; no production J2G behavior was changed.
