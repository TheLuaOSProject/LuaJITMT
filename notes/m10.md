# M10 Notes

Generational-mode startup:

- Added the public `collectgarbage("generational")` /
  `collectgarbage("incremental")` control surface. Lua callers receive the
  previous mode as `"incremental"` or `"generational"`.
- Added `GC2State.generational` as the passive mode bit and exposed it through
  `collectgarbage("stats").generational`.
- Added force-major plumbing and cycle-kind telemetry. Full GC sets a one-shot
  major override before mark begin, while generational allocation-triggered
  mark begins record `minor_cycle_requests`; fully minor starts are counted once
  minor sweep/root gates have latched.
- Entering public generational mode now schedules a one-shot major baseline so
  the first generational cycle establishes old marks before later minor cycles
  can rely on remembered-set filtering.
- Idle generational mode now keeps TG barriers enabled and records conservative
  remembered entries into the existing SSB without draining outside a cycle.
  SSB overflow records `remembered_overflows` and requests a forced major cycle
  instead of creating grey work while idle.
- Minor-request mark starts now flush and drain queued remembered entries only
  after mark bits are cleared, with `remembered_drained` tracking consumed
  entries. Forced major starts flush and drain before clearing so remembered
  entries are not treated as major-cycle roots.
- Cycle exits flush and drain SSB work before publishing IDLE, then install the
  idle barrier/allocation mode without creating grey work outside an active
  cycle.
- Arena sweep now routes through a latched `cycle_sweep_minor` identity with a
  public `minor_sweep_enabled` gate that turns on after the first generational
  major baseline. The direct arena regression still flips the gate manually to
  verify that minor sweep keeps survivors black.
- Remembered barriers now have pair-aware old-to-young filtering behind the
  same internal gate. Table/object barrier macros pass the parent container to
  GC2; with the gate enabled, old-parent/young-child stores queue the parent
  while non-young children increment `remembered_filtered`.
- Minor root selection now has matching cycle latches and a public
  `minor_roots_enabled` gate that also turns on after the first generational
  major baseline; later public generational cycles can use the minor scanner.
- Added a gated `lj_gc2_scan_minor_roots()` path that scans active TG/thread
  roots and the requested owner stack without scanning registry/global roots.
  `HS_SCAN_ROOTS` now routes through `lj_gc2_scan_cycle_roots()`, selecting the
  minor scanner when `cycle_roots_minor` has latched.
- Added an internal smoke test for remembered-set minor marking: an old parent
  queued while idle is drained and traversed at minor mark begin to mark its
  young child without relying on stack roots.
- Added `lj_gc2_barrier_tvn_pair_g()` and routed the x64 `BC_TSETM` batch
  value barrier through it, giving constructor range stores parent context for
  old-parent/young-child remembered-set filtering.
- Added `lj_gc2_barrier_tv_pair_g()` and routed the x64 fast `TSETV`,
  `TSETB`, and `TSETR` single-slot value barriers through it, giving array
  stores the destination table parent for remembered-set filtering.
- Added `lj_meta_tsettv_pair()` and routed the x64 `vmeta_tset` returned-slot
  copy through it, giving slow/generic table stores the resolved destination
  table parent without passing raw owner pointers through VM scratch state.
- C API `lua_settable()`/`lua_setfield()` and FFI cdata table-valued
  `__newindex` stores now run `lj_gc2_barrier_tv_pair()` after the release-copy
  into the resolved owner slot. This keeps resolved-proxy table stores from
  relying on the earlier `lj_meta_tset_owner()` publication barrier, which can
  be drained before the value is visible and would otherwise miss
  old-parent/young-child remembered pairs.
- `lj_gc_pubuv()` now derives the owning `GCupval` from `&uv->tv` and sends the
  acquired value snapshot through the parent-aware GC2 value barrier.
- The Linux/x64 trace-local `ASTORE`/`HSTORE` helpers now lower through
  `lj_tab_storetv_forjit_array()` and `lj_tab_storetv_forjit_hash()`, deriving
  the table parent from AREF/HREF IR and using the pair barrier instead of
  treating traced table values as parentless roots. The hash helper also carries
  the resolved `Node.key` into the P_WEAK weak-write bridge.
- Added an M10 runtime regression for traced helper-backed array stores in
  idle generational mode: an old parent table receives a young child through
  the JIT helper path, the remembered SSB tail is asserted to be the parent
  table rather than the child value, and the following minor cycle marks the
  young child through the remembered parent.
- Audited the remaining parentless TValue barrier users: production uses now
  flow through root-slot wrappers, and the stale x64 `vm_gc2_barriertv`
  subroutine was removed so VM table stores cannot regress to value-only
  remembered entries.
- Public generational mode now keeps minor sweep/root gates off until the first
  forced major baseline completes, then enables both gates for subsequent minor
  requests; switching back to incremental clears the gates.
- Minor cycle exits now compute a conservative young-survival estimate from
  `max(live_after - previous_live, 0) / cycle_alloc_bytes`, publish the last
  survival bytes/percentage through `collectgarbage("stats")`, and request a
  one-shot major when survival reaches the default 80 percent threshold.
- Added benchmark controls for M10 tuning: `BENCH_GC_MODE` pins incremental or
  generational mode and `BENCH_SCALE` runs shorter probes without changing the
  canonical default benchmark iteration counts.
- Added `tests/t-gc-generational-mode.lua` and `tools/ci/m10_generational.sh`
  to guard the API constants, mode stores, stats field, minor-gate transitions,
  and Lua-visible mode transitions.
- Preliminary tuning probes keep the survival threshold at 80 percent:
  short-lived `alloc_tables` churn reports zero survival-major requests, while a
  retained-table probe requests major cycles after high-survival minors.
- `major_cycle_starts` now counts only actual major or gate-deferred
  generational starts. Once `cycle_roots_minor` is latched, fully minor
  generational cycles leave the major counter flat while still incrementing
  `minor_cycle_requests`, and `minor_cycle_starts` records the actual minor
  start, so the benchmark stats no longer double-count minor cycles as major
  starts.
- Root-scan selection now has explicit `major_root_scans` and
  `minor_root_scans` telemetry exposed through `collectgarbage("stats")` and
  `bench_mt.lua`. The traversal harness asserts a latched minor-root handshake
  increments only the minor counter and leaves the full/global-root counter
  flat.
- Minor root scans now include GC2-owned pending roots: the finalizer MPSC/ring,
  live thread userdata, and pending FINREG cdata preclaims. These remain outside
  user global/registry roots, but they must survive minor cycles because mark
  begin clears GC2 marks for all objects. The traversal harness pins this with a
  cdata preclaim object that is marked by the minor scanner while the registry
  table stays unmarked.
- Minor-sweep cycles now preserve existing GC2 mark bits instead of clearing the
  whole heap at mark begin. Remembered SSB entries still force traversal even
  when their parent was already marked, so old-to-young stores are discovered
  while unremembered old survivors remain black until the next major. The M10
  C harness pins this with an old unremembered table plus a remembered
  old-parent/young-child pair.
- True minor cycles keep MARK/WEAK allocation black so post-snapshot objects
  cannot be reclaimed by the same cycle, then switch to white allocation when
  entering SWEEP. Gate-deferred minor requests and forced/major cycles still
  allocate black. The allocation-accounting harness asserts the phase colors,
  late attach catch-up, and remembered old-parent/young-child discovery.
- GC2 sweep now CAS-splices GC2-unmarked objects out of the legacy root chain
  before invoking legacy type destructors. This is required for cdata
  destructors that enqueue finalizers and reuse `nextgc`; it also prevents a
  raw root splice from overwriting a concurrent root-list publication. Arena
  body reuse remains owned by the bitmap sweep.
- Added `minor_cycle_starts` telemetry for fully minor mark begins, incremented
  only when the minor-root latch is active. This separates generational requests
  from actual minor cycles in `collectgarbage("stats")`, `bench_mt.lua`, and the
  M10 allocation-accounting harness.
