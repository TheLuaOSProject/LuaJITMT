This lockless fork is a source build for x86-64 Linux with GC64. Other operating systems, non-x64 CPUs, 32-on-64 GC mode, MSVC/MinGW batch builds, console builds, and Lua 5.2 compatibility builds are intentionally unsupported by this fork.

Requirements

  • x86-64 Linux.
  • GNU Make.
  • GCC or Clang/LLVM with pthread, dl, and math libraries.

The source guard in src/lj_arch.h rejects unsupported targets so stale compatibility builds fail at compile time instead of producing a partial runtime.

Building

Run a native build from the repository root: 

make

For an amalgamated build: 

make amalg

Do not pass -DLUAJIT_DISABLE_GC64 or -DLUAJIT_ENABLE_LUA52COMPAT; both are outside the supported lockless runtime surface.

Installing

The default prefix is /usr/local: 

sudo make install

Use PREFIX and DESTDIR for package builds: 

make PREFIX=/usr
make install PREFIX=/usr DESTDIR=/tmp/buildroot

Embedding

Embed this fork like a normal LuaJIT 2.1 library on x86-64 Linux. Classic Lua/C API modules must obey the fork's thread-safety rules when they run in a shared heap with multiple OS threads.
